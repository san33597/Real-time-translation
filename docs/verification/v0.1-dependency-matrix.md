## Translation (R0 product decision recorded 2026-10-09; R4 implementation pending)

- **Selected product strategy: Option B**, auditable local translation with no runtime telemetry by default. Do not integrate ML Kit. This resolves the earlier A-vs-B privacy decision; it does **not** mean any local model is selected or zero-telemetry has been verified.
- **R4 local runtime/model selection remains open:** evaluate Android-capable EN→ZH translation models by quality, speed, CPU/RAM/thermal cost, license, source integrity, per-file hashes, compatibility and absence of implicit network/telemetry. Record complete details before integration.
- **Optional cloud connector (later separately scoped):** support user-supplied DeepSeek and other API providers through a versioned TranslationProvider interface, independently of ASR. The default must remain LOCAL; cloud must require explicit choice and clearly show that the recognized text and any selected context leave the device.
- **Hard privacy rule:** cloud mode may transmit only the English text/context the user authorizes, never raw microphone/system audio. No implicit cloud fallback after local errors; retries, request scope, history and costs are explicit. Distinguish local zero-runtime-egress tests from user-authorized cloud egress.
- API secrets must never be committed, logged or hard-coded into an APK; use per-device secure storage (Android Keystore-backed encryption or vetted equivalent), TLS, narrowly scoped credentials, redaction, and per-user explicit provider enablement.
- DeepSeek currently documents OpenAI-compatible `POST /chat/completions` with base URL `https://api.deepseek.com` (model names are provider-configured; consult latest docs before implementation). https://api-docs.deepseek.com/zh-cn/
- Prior ML Kit candidate 17.0.3 is **rejected** under Option B's initial zero-telemetry requirement; prior SDK terms/disclosure are retained only as selection rationale: https://developers.google.com/ml-kit/android-data-disclosure

## R1 privacy decision

R1 uses fake resources only. Declared permissions: RECORD_AUDIO, foreground service and its two types, and POST_NOTIFICATIONS. ACCESS_FINE_LOCATION and broad storage permission are forbidden. Internet permission is intentionally deferred until model download is implemented. `allowBackup=false` and Android 12+ data extraction exclusions protect future local history by default; actual transfer behavior remains a device acceptance case.

## Remaining gates before R2/R3/R4

- **CLOSED (decision):** user selected Option B: auditable self-managed local translation, no ML Kit; cloud translations may be offered only as explicit opt-in.
- **OPEN (implementation):** select and verify the local translation model/runtime, integrity, licensing, offline performance and network behavior.
- Record target phone API/ABI and actual foreground-service permission flow results.
- Pin native AAR URL/revision/SHA-256 and exact model-file bytes/checksums/licenses before R3.
- Run Gradle unit, lint and assemble; capture evidence from GitHub CI and real Android device.
- Record third-party licenses before packaging assets.

R0's **A-vs-B policy decision is closed**; R0 dependency verification and target device/ABI and later model/native artifact gates remain open. This is not authorization to ship cloud requests, not proof of zero telemetry, and does not change the separately verified R1 simulation.
