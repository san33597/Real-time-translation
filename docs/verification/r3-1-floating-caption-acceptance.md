# R3.1: 在其他应用上显示英文字幕

状态：R3 英语 ASR + 前台服务延续；新功能需 CI 和小米/HyperOS 真机验证。**不接入 ML Kit 或 DeepSeek。**

## 工作方式
- 在应用内主动开启「在其他应用上显示英文字幕」，未授权时跳转系统「显示在其他应用上层」页面；拒绝不影响应用内字幕。
- 开始系统声音识别并按 Android 原有提示授权屏幕音频共享。返回视频应用后，前台服务保持录音+离线识别，屏幕下方以一段非交互式文字窗口显示最新英文字幕。
- 回到本应用时自动隐藏跨应用悬浮层；未在采集、不显示空字幕、停止采集、权限丢失或服务退出时立即撤销悬浮窗口。
- 窗口使用 `TYPE_APPLICATION_OVERLAY` + `FLAG_NOT_FOCUSABLE` + `FLAG_NOT_TOUCHABLE`，Window Alpha = 0.75，降低 Android 12+ 非可信悬浮窗拦截底层触摸的风险。**悬浮层不能直接拖动或点按**，按钮仍在应用内与前台通知里。
- 只显示最近 partial 或最新一段 final 的尾部文字、最多 3 行；5.5 秒没有新结果会自动隐藏；不存字幕、录音或截图。长期字幕全文只在内存已有的字幕状态中管理。
- R2 的 MediaProjection、两类音频来源、通知栏打开应用与「停止采集」不改动。

## 小米 13 / HyperOS 测试顺序
1. 安装 R3.1 调试 APK（同包名升级，不卸载，避免清除已导入的私有模型）。
2. 打开应用，开启「在其他应用上显示英文字幕」→ 在系统权限页允许「显示在其他应用上层」，返回应用后查看开关状态。
3. 选择系统声音并开始英文识别，完成每次必须重新请求的 Android MediaProjection 授权。
4. 打开支持 Android 播放音频采集的英文视频，在视频画面下方观察悬浮英文字幕。检查它不会抢焦点或阻止暂停/播放、滑动、拖动进度条。
5. 重新打开应用应仅显示应用内字幕，悬浮层不重复出现。再次转到视频应用，应恢复悬浮字幕。
6. 在应用内关闭悬浮字幕开关，不应影响识别与音频计数；再开启应能恢复显示。
7. 通过通知栏「停止采集」后悬浮层应立即消失，重新打开应用状态应为 Idle；再次启动 SYSTEM 必须重新授权屏幕捕获。
8. 测试无声 30 秒、系统撤销屏幕共享、手动撤销悬浮窗权限、反复切前台/后台与连续播放 10–15 分钟。
9. 检查系统权限界面 / 支付等敏感页面：Android 可能主动屏蔽第三方悬浮层，这不是识别停止。锁屏或播放来源策略也可能影响实际显示。

## 已知限制
- 首版是固定底部、居中的非交互悬浮字幕，不支持拖动、手动缩放、多主题或自动横屏重排。
- 部分 OEM 有额外后台/悬浮窗限制，需在 Xiaomi 实机确认。没有申请后台弹出 Activity 权限。
- 旧 R3 字幕管理仍有 `take(240)` 长句截断风险，R3.1 悬浮层只压缩视觉展示，不声称已修复内部截断；后续需单独修复。
- 此版本仍为英文识别，不包含中文翻译。
